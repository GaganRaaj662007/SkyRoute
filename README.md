# SkyRoute - Flight Reservation System

## Project Description
SkyRoute is a web-based flight reservation system developed
for the Software Design Foundations (CSC203B) assignment.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Features
- Search flights
- View available flights
- Calculate total fare
- Enter passenger details
- Confirm flight reservations
- Generate unique booking IDs
- Print reservation details
- View booking history
- Cancel reservations
- Input validation

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required package:

   python -m pip install -r requirements.txt

4. Run the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

The SQLite database is automatically created when
the application starts.

## Disclaimer
This project is an academic demonstration.
It uses sample flight data and does not provide
real airline reservations or payments.
